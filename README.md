## Publicar no GitHub Pages

1. Crie um repositório no GitHub e suba esta pasta (mantendo `index.html` na raiz).
2. Em **Settings → Pages**, selecione a branch (ex: `main`) e a pasta `/ (root)`.
3. O site fica disponível em `https://<seu-usuario>.github.io/<repo>/`.
